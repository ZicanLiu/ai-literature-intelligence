# 第二周任务样例

本目录用于保存第二周各任务经过整理、来源清楚且体积适中的 OpenAlex live 样例或摘要。
约定的任务子目录如下，由对应成员提交成果时创建：

- `openalex_client/`
- `dedup/`
- `domain_query/`
- `quality_gate/`
- `ranking/`
- `integration/`

每份样例至少记录 `keyword`、`run_id`、运行时间和记录数量，并附来源或生成说明。不要
提交完整的普通实验目录、API Key、无法解释来源的数据或未经授权的论文全文。这里的
样例只用于开发、测试和人工分析，不是完整或权威的天文光谱文献集。
