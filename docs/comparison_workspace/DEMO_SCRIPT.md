# 3–5 分钟组会演示

准备：首次安装和前端构建在组会前完成。运行 python -m app.comparison_workspace_main；
浏览器打开 http://127.0.0.1:8765。无需 Key、无需网络。不要使用真实 / 私人论文作默认 demo。

| 时间 | 操作 | 说明 |
| --- | --- | --- |
| 0:00–0:30 | 首页点击“体验合成演示” | 三个自制 PDF，醒目标识不是真实研究证据 |
| 0:30–1:10 | 查看每篇两个候选 / 一个活动结果；浏览矩阵 | 比较的是明确的目标实验，不是笼统整篇论文 |
| 1:10–1:40 | “报告数字”下看 92 / 89 / 91；点击“允许差异” | 报告数字可排序，split 差异展示为背景，不自动阻断 |
| 1:40–2:20 | 切换“相同协议”，运行分析，点击“阻断” | A random / B temporal 阻断相同协议问题；B 预处理未知仍单独未决 |
| 2:20–2:50 | 点击 B 的划分单元格，展开页面文本 / PDF 第 2 页 | 引文与页码可核对；原文出现不代表解释正确 |
| 2:50–3:20 | 分别固定 A / B 的划分证据，“并排查看” | 比较两个来源而非只看模型叙述 |
| 3:20–3:50 | 切换“资源效率”，运行分析，看“未决” | B/C 资源证据缺失；不编造效率指标 |
| 3:50–4:30 | 修订一个观察，填写理由；回首页重开 | 用户修订有独立标识与历史；旧分析 STALE |
| 4:30–5:00 | 导出 Markdown，再展示 JSON / CSV 可选项 | 持久化、可追溯与可复核工作流；没有新 benchmark 或有效性主张 |

如修改活动结果：先展示 STALE，再重新运行。内置叙述只针对默认主实验；
目标或内容修订后用“未决”提示复核，避免把固定 demo 解释套到新输入。

真实 PDF 路径的另一个演示：新建问题 → 上传 2 篇 → 阅读源页 / 定位证据 →
手工结果 / 观察 / 四类判断 → 保存并导出。没有 Key 时明确使用手工模式。
