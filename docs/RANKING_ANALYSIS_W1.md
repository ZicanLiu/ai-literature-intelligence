## 1. 评分机制回顾

```
preliminary_score = 0.40*relevance + 0.30*impact + 0.20*recency + 0.10*completeness
```

- relevance：关键词词项在标题（70%）和摘要（30%）中的命中比例，纯词项集合匹配，无语义判断。
- impact：log1p(引用量) / 本批最大值，**与主题相关性完全解耦**。注意 impact 依赖本批最大引用量，100 篇批次中出现了更高被引论文，所有 impact 分较 60 篇批次整体下移（例如 W3155899199 从 0.7603 降为 0.6173），但异常条目依然留在前 20。
- recency：发表年份距今线性衰减，10 年以上为 0。
- completeness：6 个字段的完整比例；前 20 全部为 1.0，无区分度。

## 4. 规律总结

1. **高被引/新近 carry（案例 A/B/F）**：impact、recency 与主题解耦，通用词命中（rel=0.5）的论文靠引用量和年份即可进前 20。100 篇批次中此类异常从 3 篇增至 3 篇但位置后移（第 16/18/19 名），新增的水管泄漏论文说明扩大检索量会引入更多跨领域噪声。
2. **词项误匹配（案例 C/D/E）**：spectra（功率谱）、stellar（恒星质量）等词命中即给高分，rel 本身成为虚高来源，此类异常排名（第 8/9/12 名）比 carry 类更靠前。
3. **completeness 无区分度**：前 20 全部 comp=1.0，该项等于人人白送 0.1。
4. **impact 批次敏感**：impact 分依赖本批最大引用量，换一批数据所有论文的 impact 都会变，同一论文在两批中分数不同（W3155899199：0.7603 → 0.6173），跨批次分数不可比。
5. **边界案例提示**：第 5/6 名中子星光谱论文属于"恒星光谱"的宽严之界，词项匹配无法处理，需人工约定主题口径。

## 5. 改进建议（简单、透明、可验证；不改 0.4/0.3/0.2/0.1 权重）

### 建议 1：相关性门槛——rel 低于阈值时 impact 与 recency 不计入总分

规则：仅当 `relevance_score >= 0.6`（即标题或摘要有实质命中）时，impact 和 recency 才参与加权；低于阈值时总分 = `0.4*rel + 0.1*comp`，并标记 `low_relevance=True` 供人工复核。

- 可解释：一句话规则——"先相关，再谈引用和新旧"，权重数值本身不变。
- 可验证：用样例 CSV 重算，案例 A/B/F（rel=0.5）总分将降至 0.30，退出前 20；案例 C/D/E（rel≥0.65）由建议 2 处理。可直接用 `ranking_cases_w1.csv` 中的分数复算核对。

### 建议 2：领域必需词项——relevance 计算增加一道"领域词"校验

规则：把关键词拆为"方法词"（machine, learning）与"领域词"（stellar, spectra）；要求标题或摘要**至少命中一个领域词**，否则 relevance 直接记 0。实现上只需在 `calculate_relevance_score` 返回前加一个条件判断。

- 可解释：machine/learning 是各学科通用词，单独命中不代表主题相关；stellar/spectra 才是本主题的身份词。
- 可验证：用样例 CSV 重算，案例 A/B（标题仅含 machine/learning）rel 降为 0，直接出榜。已知边界：该规则对案例 D（标题含 spectra 但指功率谱）和案例 C（标题含 stellar 但指恒星质量）无能为力，这两类需要词组级或人工口径，文档中明示即可。

两条建议均可只在 `add_preliminary_scores` / `calculate_relevance_score` 内以 <15 行代码实现，且可用现有 100 篇样例离线重放验证，不需要改权重、不需要引入外部模型。
