# 当前项目状态

更新时间：2026-07-27
稳定版本：v0.2.0
本次整理基于：`main` 提交 `0d743cb`

## 已验证范围

当前主流程支持本地 mock 或 OpenAlex live 元数据获取、字段清洗、DOI/标题严格
去重、缺失统计、`preliminary_score` 初步排序、CSV、SQLite、两张图表和运行摘要。
live 模式已有历史小规模真实测试记录；本次基线整理只使用 mock，不读取真实 Key，
也不重新请求 OpenAlex。

`preliminary_score` 是一条透明、可解释的项目内部基线规则，不代表论文真实学术价值，
其权重尚未经过统一人工评价数据验证。

## 当前真实样例与第一周成果

- `data/samples/openalex_stellar_spectra_100.csv`：100 条 OpenAlex live 元数据，
  检索词为 `machine learning stellar spectra`。
- 字段审计、领域查询设计、前 20 名排序复核和第一周总结已归档到
  `docs/reports/week1/`。
- `data/analysis/` 保留字段审计与排序复核表，`data/manual/` 保留人工标注文件。
- 当前人工相关性标注没有与统一 100 条样例建立可复查的 ID 对齐关系，并存在一行
  CSV 转义异常；在修复前不能作为排序评价集。

## 第二周开始前的基线变化

- 项目说明、协作规范、第一周报告和 live 验证记录已分类到 `docs/project/`、
  `docs/collaboration/` 和 `docs/reports/`，并由 `docs/README.md` 统一索引。
- 普通 CLI 运行默认写入 `outputs/experiments/<run_id>/`，每次运行生成唯一目录，
  相同或不同关键词都不再覆盖历史实验。
- 每个实验包含 `run_config.json`、原始响应、两张 CSV、SQLite、图表和运行摘要；
  配置保存完整关键词、参数、评分权重、数量、耗时和成功状态，不保存 Key 或个人绝对路径。
- 第一周根目录中的两个测试文件经确认均为 0 字节，已由可执行的离线自动测试、
  手工测试记录和测试报告替代。
- 当前自动测试共 7 个，最终 7 通过、0 失败、0 跳过；覆盖 CLI 产物、输出隔离、
  参数边界、中文路径和计数一致性。
- 普通实验目录默认不提交；确认需要长期保存的结果应经过检查后提升到
  `outputs/baselines/`，不得直接把临时结果当作基线。

## 当前明确不包含

当前版本不包含 PDF 解析、RAG、Embedding、多 Agent、知识图谱、Web 前端，也不包含
分页抓取或经过人工验证的学术价值评价模型。此前 PDF 解析仅为临时演示，已删除。

## 待确认与第二周重点

1. 用统一 100 条样例修复并扩充人工相关性标注，统一边界对象口径。
2. 为 OpenAlex 文本中的 HTML 标记、跨领域混入和字段缺失建立小范围可测规则。
3. 在人工标注可追溯后建立检索与排序的定量评价闭环，不先凭直觉调整评分权重。
4. 继续补充处理模块的单元测试；本次自动测试重点是 CLI、输出隔离和计数一致性。
5. live 模式本次未验证，后续只能由合法配置 Key 的成员按需执行。

以上状态表示第二周可以从统一基线继续分支开发，不表示项目已经完成工程化。
