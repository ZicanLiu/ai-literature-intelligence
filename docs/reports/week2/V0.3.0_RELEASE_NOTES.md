# v0.3.0 候选发布说明

状态：**候选，尚未发布**。本文件描述 `feat/w2-unified-pipeline` 未提交工作区达到的
集成范围；只有代码评审、提交并合并后，才能决定是否发布 v0.3.0。

## 候选新增

- 多 acquisition query 的统一 parent run；
- 清洗后附加、精确去重时合并的 provenance；
- 显式且独立的 ranking keyword；
- 旧 `preliminary_score` baseline 与现有 TF-IDF/Stage 1/Stage 2 串联；
- 不自动删除的 suspected review queue；
- 保留 W2 字段的阶段化输出和可复现 `run_config.json`；
- 默认排除 AI-assisted/待复核行的可选 judged 评价；
- 复用统一 Pipeline API 的 Batch Runner；
- 离线 E2E、失败边界和 batch 继续策略测试。

## 兼容性

`python -m app.main`、旧 OpenAlex client、v0.2 processor/storage/visualizer、历史 fixture 与
baseline 均保留。`find_exact_duplicates()` 新参数默认关闭，既有调用行为不变。

## 限制

当前 TF-IDF 仍是词法相关性 baseline；`preliminary_score` 不代表论文真实学术价值。
人工标签未完成全部复核，评价结果只能作为开发诊断。v0.3 候选没有包含 PDF 解析、RAG、
多 Agent、Embedding、知识图谱或前端。
