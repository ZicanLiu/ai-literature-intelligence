# W5 检索错误案例分析报告

## 1. 任务概述
本任务基于W4的文献标注结果，筛选出label=0的检索失败案例，对检索出错原因做分类标注，一共得到**12条错误样本**。
错误类型分为三类：
- `hard_negative`：字面关键词匹配，但核心研究任务完全无关
- `topic_drift`：属于同一专业领域，但偏离查询的核心研究问题
- `term_ambiguity`：专业术语歧义、方法名词复用带来混淆

## 2. 错误类型统计
| 错误类型 | 数量 |
|---|---|
| hard_negative | 5 |
| topic_drift | 5 |
| term_ambiguity | 2 |
| 合计 | 12 |

## 3. 各类错误典型案例

### hard_negative（5例）
检索命中关键词，但论文不属于恒星光谱研究领域。
1. w4_rq01_014：无线通信领域机器学习调制识别，和天文完全无关。
2. w4_rq02_020：星震学恒星内部物理研究，不做光谱参数估计。
3. w4_rq03_011：星系SED降噪自编码器，对象是星系而非恒星光谱。
4. w4_rq03_015：X射线超新星成像，和光谱预处理无关。
5. w4_rq03_018：矿山突水预测，只是使用XGBoost，和天文毫无关系。

> 问题根源：通用机器学习关键词没有绑定领域约束，检索把其他学科使用同类算法的文献召回。

### topic_drift（5例）
论文属于天文恒星领域，但回答的不是查询提出的科学问题。
1. w4_rq01_010：用机器学习测恒星自转周期，不是光谱分类。
2. w4_rq01_015：做星‑星系分类和温度回归，不针对恒星光谱分类任务。
3. w4_rq01_016：恒星分类算法实验，目标和查询任务存在偏移。
4. w4_rq02_014：识别碳星，不是从光谱估计恒星大气物理参数。
5. w4_rq03_012：deep‑REMAP用于光谱参数反演，**不是光谱预处理降噪校准**。

> 问题根源：领域大主题匹配成功，但没有区分子任务之间细微差异。

### term_ambiguity（2例）
方法术语复用，语义混淆。
1. w4_rq02_002：t‑SNE用于丰度空间降维分析，并非用来估计恒星物理参数。
2. w4_rq03_006：variational inference去除Kepler测光系统噪声，不是光谱预处理。

> 问题根源：降维、变分推断这类通用方法被多处场景使用，检索无法区分它用来解决哪一类子问题。

## 4. 针对检索系统的优化建议
1. **解决hard‑negative**：增加领域过滤约束，在查询中加入领域关键词，过滤非天文文献；构建领域停用/黑名单，减少跨学科无关文献召回。
2. **解决topic_drift**：不能只依赖词法匹配，需要区分子任务；引入任务级语义表示，区分“光谱分类”、“参数估计”、“预处理”不同子问题。
3. **解决term_ambiguity**：术语不能单独看，要结合上下文；把【方法+研究对象+科学任务】三者联合做语义匹配，避免只匹配方法名词。
