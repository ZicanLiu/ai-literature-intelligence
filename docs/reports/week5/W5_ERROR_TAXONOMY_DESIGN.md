# W5 错误分类体系设计文档


## 1. 设计目标
本分类体系基于W4已冻结的人工标注结果，为恒星光谱检索任务的失败案例提供机器可解析、可复用的分类标签，支撑不同检索方法的错误归因与性能分析。


## 2. 分类原则
1. **不修改W4基准**：完全基于已冻结的`label=0`标注结果，不重新人工判断标签
2. **可机器解析**：每个分类标签有明确的判定规则，可通过脚本自动统计
3. **领域适配**：针对天文文献检索的特有场景设计，通用且不丢失领域特异性
4. **兜底机制**：无法明确分类的案例统一归入`unclassified`，不强行制造类别


## 3. 分类体系详情


### 3.1 hard_negative（硬负例）
- **定义**：检索结果与查询关键词存在字面重合，但核心研究领域、科学任务完全无关，属于跨学科无关文献
- **典型场景**：
  - 机器学习关键词匹配，但论文属于无线通信、矿山工程等非天文领域
  - 通用算法名词匹配，但研究对象完全不是恒星/天文光谱
- **判定规则**：论文核心研究领域不在天文/恒星物理范畴，与查询的科学问题无任何关联


### 3.2 topic_drift（主题偏移）
- **定义**：论文属于天文/恒星物理领域，但研究的子任务、科学问题与查询核心需求存在偏移
- **典型场景**：
  - 查询问「恒星光谱分类」，论文做「恒星自转周期测量」
  - 查询问「光谱参数估计」，论文做「碳星识别」
  - 查询问「光谱预处理降噪」，论文做「光谱参数反演」
- **判定规则**：领域匹配，但核心研究任务与查询问题不一致


### 3.3 term_ambiguity（术语歧义）
- **定义**：通用方法、术语名词复用，导致语义混淆，检索匹配到同名但不同用途的技术
- **典型场景**：
  - 「t‑SNE」降维方法，用于丰度空间分析而非参数估计
  - 「variational inference」变分推断，用于测光数据噪声去除而非光谱预处理
- **判定规则**：方法名词匹配，但方法的应用场景、解决的子问题完全不同


### 3.4 unclassified（未分类）
- **定义**：无法归入以上三类的特殊案例，作为兜底类别
- **判定规则**：不符合以上三类任何一种明确判定标准的案例


## 4. 分类使用规范
1. 每条错误案例仅分配一个分类标签，优先匹配明确规则，最后兜底`unclassified`
2. 分类标签仅用于错误归因，不修改W4基准的label标注结果
3. 统计分析时，`unclassified`类别单独列出，不与其他三类合并
4. 本分类体系可复用于后续W5所有检索方法的错误分析
