# 后续路线图

第一版故意保持简单，只完成从文献获取到结构化保存和初步排序的最小闭环。下面这些功能暂时不做，后续再逐步扩展。

## 第一版暂时不做的功能

### 1. Crossref DOI 二次校验

第一版只使用 OpenAlex 或 mock 数据中已有 DOI，不调用 Crossref 做二次校验。

### 2. 标题模糊去重

第一版只在 DOI 缺失时按标准化标题完全相同去重，不做编辑距离、模糊匹配或近似标题判断。

### 3. TF-IDF 或 Embedding 语义相关性

第一版的相关性只看关键词是否出现在标题和摘要中，不使用 TF-IDF、Embedding 或语义模型。

v0.2 使用完整英文数字词项匹配，避免关键词匹配到其他单词内部；词干还原、同义词扩展和语义匹配仍留待后续评估。

### 4. 摘要大模型结构化提取

第一版不调用大模型 API，不从摘要中抽取任务、数据集、方法、指标等复杂结构。

### 5. 人工评价样本

第一版没有人工标注的文献评价样本，因此排序公式只是辅助初筛规则。

### 6. 更完善的价值评价模型

第一版不声称判断论文价值，只提供“初步文献排序”。后续如果加入人工样本和更多指标，才可以讨论更完善的评价模型。

### 7. 多领域主题切换

第一版围绕“AI 在天文光谱数据处理中的应用”设计，暂时不做多领域配置。

### 8. Web 前端

第一版只提供命令行入口，不实现网页前端、Streamlit 或可视化交互界面。

### 9. PDF 全文解析

第一版只处理文献元数据和摘要，不下载、不解析 PDF 全文。

### 10. RAG

第一版不构建向量库，不做检索增强生成。

### 11. 多 Agent

第一版不实现 LangGraph、多 Agent 或复杂调度框架。等最小流程稳定后，再考虑是否需要引入。

### 12. OpenAlex 多页抓取

v0.2 单次最多请求 100 条，不实现 cursor 分页。分页和更大结果集的请求控制留作后续功能。

## 建议扩展顺序

1. 增加少量人工评价样本，用于观察初步排序是否符合人工阅读体验。
2. 增加 Crossref DOI 校验，提高元数据可靠性。
3. 加入更细的摘要结构化字段，例如研究对象、方法、数据来源。
4. 再考虑 TF-IDF 或 Embedding，提高相关性计算能力。
5. 最后再考虑 Web 前端、RAG 和多 Agent。
